# 自分専用AIコンソール（仮）

## 着想

リアルタイム音声AIとの会話で感じる映画的な没入感を、自分のための静かな操作空間として捉え直す。特定の映画に固有の名称、台詞、画面表現、意匠は模倣せず、会話と状態が自然につながる独自の体験を考える。

## 狙う世界観

深い暗色を基調に、光は控えめに使う。常に動き続ける演出ではなく、必要な変化だけが静かに現れ、AIの状態や気配を落ち着いて把握できる空間を目指す。

## 想定する二層

- 利用者向け: 会話に集中でき、不安や圧迫感を与えない落ち着いた安心感。
- 運用向け: 状態や出来事をひと目で追える、司令室のような情報密度。

## 今は実装しないこと

技術選定、機能一覧、詳細な画面構成、大きな仕様、既存プロジェクトとの統合は決めない。まずは再開できる着想として保存する。

## 再開時の最小一歩

二層の雰囲気を一枚で比較できる静止画ラフを作り、暗色、控えめな光、静かな状態可視化が両立して見えるかだけを確認する。
